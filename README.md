Site completo e otimizado com **392 grupos brasileiros verificados** (Bate-Papo & Amizade em destaque no topo).

---

## 🚀 Como subir no GitHub e colocar no ar na Vercel (em 2 minutos)

### Opção 1: Pelo Navegador (Sem digitar comandos)

1. **Acesse o GitHub:**
   - Entre em [github.com/new](https://github.com/new) e crie um novo repositório (ex: `grupos-telegram-br`).
   - Deixe como **Public** (Público).

2. **Suba os arquivos:**
   - Clique em **"uploading an existing file"** (carregar arquivos).
   - Arraste todos os arquivos desta pasta:
     - `index.html`
     - `grupos.json`
     - `vercel.json`
     - `package.json`
     - `README.md`
   - Clique em **Commit changes** (Salvar).

3. **Deploy na Vercel:**
   - Entre em [vercel.com](https://vercel.com) e faça login com seu GitHub.
   - Clique no botão azul **"Add New..."** ➔ **"Project"**.
   - Escolha o repositório `grupos-telegram-br` e clique em **"Import"**.
   - Clique em **"Deploy"**.
   - Em menos de 15 segundos seu site estará no ar com link HTTPS mundial grátis (ex: `https://grupos-telegram-br.vercel.app`)!

---

### Opção 2: Pelo Terminal (Git)

```bash
git init
git add .
git commit -m "Site de Grupos BR Telegram pronto para Vercel"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
git push -u origin main
```
Em seguida, vá na Vercel e importe o repositório.
